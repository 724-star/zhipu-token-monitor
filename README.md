# 智谱Token活动自动监控脚本

持续监控智谱官方的免费Token/额度发放活动，一旦出现可领取的福利，自动完成领取操作，全程无需手动干预。

## 功能特点

### 核心功能
- **自动监控**: 持续监控智谱官方活动页面
- **智能检测**: 自动识别可领取的Token活动按钮
- **自动领取**: 发现活动后自动点击领取
- **会话保持**: 复用已登录的智谱账号会话
- **异常处理**: 网络超时自动重试，检测失败自动恢复
- **桌面通知**: 重要事件实时弹窗通知

### 监控策略
- **日常监控**: 周一至周四，每30分钟检查一次
- **高峰监控**: 周五18:00至周一10:00，每5分钟检查一次
- **智能检测**: 支持多种领取按钮识别
- **自动确认**: 处理简单的确认弹窗

### 安全特性
- **SSL跳过**: 关闭SSL证书校验，避免证书问题
- **会话加密**: 本地保存加密的登录会话
- **日志记录**: 所有操作详细记录日志
- **异常通知**: 异常情况即时通知用户

## 安装部署

### 1. 前置要求
- Windows 10/11系统
- Python 3.7+ 环境
- 网络连接

### 2. 安装步骤

1. 将所有文件复制到目标目录：`E:\zhipu专用地`

2. 首次使用时，运行安装脚本：
```bash
python install_monitor.py
```

3. 安装完成后，首次启动需要手动登录智谱账号：
```bash
python zhipu_token_monitor.py
```

4. 登录成功后按 `Ctrl+C` 停止脚本，会话将自动保存

### 3. 文件说明

```
E:\zhipu专用地/
├── zhipu_token_monitor.py    # 主监控脚本
├── install_monitor.py         # 依赖安装脚本
├── start_monitor.bat          # 启动脚本
├── stop_monitor.bat           # 停止脚本
├── check_status.bat           # 状态检查脚本
├── README.md                  # 说明文档
├── .browser_data/             # 浏览器数据目录
│   └── cookies.json          # 登录会话文件
└── token_monitor.log          # 运行日志文件
```

## 配置说明

```python

    "https://open.bigmodel.cn/user/benefits",
    "https://open.bigmodel.cn/activity/zcode"
```

## 通知类型

脚本会在以下情况发送桌面通知：

1. **发现新活动**: 检测到可领取的Token活动
2. **领取成功**: 成功领取Token，显示当前余额
3. **领取失败**: 领取过程中出现错误
4. **需要手动处理**: 检测到验证码等需要手动操作
5. **异常停止**: 脚本异常退出

## 日志说明

日志文件 `token_monitor.log` 记录所有操作，包括：

- 启动/停止时间
- 页面检查结果
- 按钮检测情况
- 领取操作记录
- 错误和异常信息
- 会话保存状态

日志文件大小限制为10MB，自动轮转保存最近5个版本。

## 故障排除

### 问题：无法启动浏览器

**解决方案**：
1. 运行 `python -m playwright install chromium` 安装浏览器
2. 检查网络连接
3. 检查防火墙设置

### 问题：检测不到活动按钮

**解决方案**：
1. 手动访问智谱活动页面，确认有活动
2. 检查关键词配置是否准确
3. 查看日志文件了解详细错误

### 问题：会话失效需要重新登录

**解决方案**：
1. 删除 `.browser_data/cookies.json`
2. 手动运行 `python zhipu_token_monitor.py` 重新登录
3. 登录成功后按 `Ctrl+C` 停止

### 问题：通知不显示

**解决方案**：
1. 检查Windows通知设置
2. 确保脚本有通知权限
3. 查看日志文件确认通知发送状态
